# v3.8.1 共振算法审计修正与反抽主攻选股实证

## 1. 对 `v3.8.0` 共振引擎的实盘审计与 5 项算法修复

通过对 `2026-11-27` 实盘 60 分钟 K 线与 800 根历史回测的交叉审查，定位并修复了以下核心漏洞（[resonance_engine.py](../backend/resonance_engine.py)）：

1. **新增 `extended（已达目标/勿追）` 状态防高位追涨**：
   - 原 `confirm_active` 在暴涨超越 `60m MA20`（`boll_z = +2.10`、`kdj_j > 110`）后仍维持 `confirm`，易诱导高位接盘。
   - 现增加 `extended = (c >= ma20 * 1.005) | (boll_z >= 0.8) | (kdj_j >= 85.0)`：越界即从 `confirm` 退出转入 `extended`；若 ≥3 个指数进入 `extended`，整体阶段切为 **「反抽已达目标（勿追高 · 分批止盈）」**。
2. **修复底背离钝化 `blunt` 窗口漂移与阴跌假背离**：
   - 必须同时满足当前价格处于低位（`c <= ma20`、`boll_z <= -0.3`、`c <= low_recent * 1.02`）及两低点之间存在 MACD 柱体翻红隔离，彻底消除暴涨后 `blunt` 依然误亮的漏洞。
3. **收紧拐头 `turn` 与超跌阈值**：
   - 超跌门槛 `50 → 55`，`ZONE_LOOKBACK_BARS 8 → 6`，`CONFIRM_HOLD_BARS 6 → 4`；站回 MA5 要求阳线实体 `> +0.3%` 且成交量不缩量（`>= 0.95 × 前5根均量`），MACD 金叉限定零轴下方。
4. **回测规则与实时逻辑同源**：
   - 回测入场只取首次突破的 `raw_confirm & ~extended` 瞬间并加入点时间权重护盘假底过滤，消除重复计次。
5. **当日涨跌幅数据源对齐**：
   - `day_pct` 优先使用 `index_engine.fetch_index_realtime` 实时快照，失败再回退 15m 推算，并在目标列显式标出 `(已达)`。

## 2. 反抽主攻题材、三类标的挖掘与 10 年点时间实证（`backend/rebound_picks_engine.py`）

### 2.1 10 年（2016–2026，798 只活跃股）点时间回测结论
基于 `backend/cache/factor_panel.npz` 严格扣减 `0.25%` 双边成本并剔除涨停买不进与停牌标的，实测对比（已于前端直接披露完整数据与幸存者偏差说明）：
- 在**左侧恐慌冰点尾盘（市场 `boll_z <= -1.8` 且日跌 `<= -1.5%`，n=48~52）**下：
  - **🏛️ 强趋势低吸（60日强前 35% + 5日回调 ≤ -2% + 缩量 ≤ 1.5x）**：`T+1 +0.88%`、`T+3 +1.34%`（相对活跃池等权基准 `+0.43%` 超额 **+0.91pp**）、`T+5 +1.73%`、3日均最大冲高 **+7.48%**；
  - 显著优于追逐高潮大涨或单纯低波动防御股。
- 在**右侧温和止跌阳**：强趋势低吸 3日均最大冲高达 **+6.03%**，同样显著领先活跃池基准（`+3.77%`）。

### 2.2 实时主攻挖掘流水线（`GET /api/index/rebound-picks`）
1. 提取 `IntradaySentimentEngine` 当日 **Top 4 主攻题材**（主力净流入 + 涨幅 + 涨停共振三因子，已过滤融资融券等伪题材）。
2. 并发抓取新浪成分股按成交额降序前 25 只，过滤 `ST/*ST/退市` 与冷门僵尸股，明确标注 **可跟踪低吸 / 已拉高勿追 / 涨停难买(情绪锚)**（每个板块最多保留 1 只涨停板作情绪风向标）。
3. 融合 `factor_panel.npz` 长周期动量，分层输出三大实战角色（`trend_pullback`、`capacity_leader`、`oversold_bounce`），并在前端支持按角色过滤与**一键跳转个股量化看板查看支撑/压力位及交易计划卡**。

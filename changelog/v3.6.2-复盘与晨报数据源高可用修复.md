# v3.6.2 — 复盘日报与明日重点数据源高可用修复

- **日期**：2026-11-27
- **类型**：`Bug修复` / `数据源高可用`
- **关联模块**：`backend/market_report.py`、`backend/intraday_engine.py`

## 1. 根因定位
东财 `push2his.eastmoney.com/api/qt/stock/kline/get` 与 `push2.eastmoney.com/api/qt/clist/get` 在当前网络环境下对服务器连接直接触发 `RemoteDisconnected` / `ConnectionResetError(10054)`，而 `market_report.py` 原先仅依赖该单一通道获取交易日历、指数日 K 与行业板块，导致复盘日报、明日重点晨报和次日预判台账整页报错无数据。

## 2. 修复内容
1. **腾讯 `newfqkline` 日 K 主源 + 东财回退**：`market_report.py` 与 `intraday_engine.py` 的指数/个股日 K 优先走腾讯 `proxy.finance.qq.com/ifzqgtimg/appstock/app/newfqkline/get`（支持全部沪深北指数与个股，`row[8]` 为真实成交额万元），东财 `push2his` 降级为备源。
2. **新浪行业板块 + 龙头股无缝回退**：`sw_industries()` 在东财 `clist` 不可达时自动回退新浪行业板块接口（48 个行业实时涨跌与资金参考），`board_leaders()` 支持通过新浪 `Market_Center.getHQNodeData` 拉取行业龙头并通过腾讯日 K 补全 MACD 与多日涨跌幅。
3. **线程局部 Session 隔离**：`MarketReportEngine` 改用 `threading.local()` 为每个并发工作线程分配独立 `Session`（`trust_env=False`），避免多线程并发连接冲突。

## 3. 验证结果
- 三套离线回归测试全部 PASS（`test_*regressions.py` 139 tests、`test_market_report.py` 13 tests、`test_display_regressions.cjs` PASS）。
- 服务重启后实盘请求 `/api/report/review`、`/api/report/focus`、`/api/prediction/journal`、`/api/intraday/sentiment` 均返回 HTTP 200 且数据完整。

# ADR-0006：冰点面板改为波动率阈值穿越模型（v3）

- **状态**: Accepted
- **日期**: 2026-09-15
- **模块**: ice
- **关联代码**: `backend/ice_engine.py`
- **关联评估**: `backend/eval_reports/ice_calibration_*.json`
- **现行规格**: [`../spec/ice.md`](../spec/ice.md)

## 背景

标签「未来10日涨幅 ≥ +2.5%」是阈值穿越事件，概率主要由波动幅度决定。分箱冰点分样本外不优于基率；方向性特征作漂移或逻辑回归亦全部失败。

## 决策

1. 模型：混合 Parkinson(20)、EWMA(λ=0.94)、Std(250) 得日方差，零漂移正态下  
   \(P(\text{10日涨}\ge 2.5\%) = 1-\Phi(2.5/\hat\sigma_d\sqrt{10})\)。权重先验 (0.4, 0.3, 0.3)，**不在标签上调参**。
2. 冰点分与情绪面保留为状态/展示，**不参与概率**。
3. 必须同时展示同口径下跌 ≥2.5% 概率（对称相等）——高概率只表示波动放大，不是看多。
4. 检验：前视重叠清洗 + 全部互不重叠切分 + 移动块自助 p + 样本外可靠性分桶。
5. 日K 主源东财 push2his，腾讯备源；实际源写入 `kline_source`；日K 缓存 30 分钟。

## 备选方案

经验分布重抽、Student-t、逻辑回归（含冰点分/价量特征）——样本外均弱于或差于本模型。

## 后果

- 四指数样本外 Brier skill 约 +0.031~+0.038（见白皮书 §15.4 归档数字）。
- skill 仅略优于基率，正确用法是波动预算/仓位宽度，不是择时方向。
- 取代 ADR-0003/0005 的概率模型路径。

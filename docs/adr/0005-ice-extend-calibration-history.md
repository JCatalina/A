# ADR-0005：拉长冰点校准历史以消除深冰档空概率

- **状态**: Superseded by [ADR-0006](0006-ice-v3-volatility-exceedance.md)（窗口拉长的工程结论仍并入 v3 数据层）
- **日期**: 2026-09-15
- **模块**: ice / data
- **关联代码**: `backend/ice_engine.py`, `backend/data_fetcher.py`（历史）

## 背景

创业板/深证冰点分打到极冷档时面板显示 `--`：`MIN_BIN_SAMPLES=30` 保护触发；短历史导致深冰档样本不足。

## 决策

校准历史拉到数据源上限（约2000根日K、两融覆盖），并修复两融磁盘缓存只校验 TTL 不校验长度的问题。

## 后果

- 五档均可出概率；但深冰档优势明显收窄，Brier skill 为负——**分箱模型样本外不优于基率**。
- 直接推动 ADR-0006 换模型，而非继续调分箱。

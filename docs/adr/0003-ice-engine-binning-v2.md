# ADR-0003：大盘冰点反弹 — 分箱条件频率模型（v2）

- **状态**: Superseded by [ADR-0006](0006-ice-v3-volatility-exceedance.md)
- **日期**: 2026-09-03
- **模块**: ice
- **关联代码**: 历史实现见 git；现行代码为 v3

## 背景

需要回答「当前是否处于值得左侧布局的情绪/资金冰点」，输出可校准的反弹概率。

## 决策

1. 特征：20日跌幅、乖离、60日回撤、连跌、量能收缩、融资余额5日变化等，转近250日冰度百分位后加权得冰点分 0–100。
2. 冰点分五箱 → 未来10日涨幅≥2.5% 命中率 + Wilson CI + PAVA；情绪面仅展示不进概率。
3. 严格点时间；交易口径另列开盘买/收盘卖期望。

## 后果

- 短窗口（约612样本）深冰档看似有优势，但后续拉长窗口与样本外检验表明**不优于基率**（见 ADR-0005/0006）。
- 保留本卡作为失败路径记录，避免重复走回「用冰点分猜方向」。

# ADR-0004：冰点引擎每指数独立校准

- **状态**: Accepted（v3 仍遵守：特征与标签同源，严禁跨指数借表）
- **日期**: 2026-09-03
- **模块**: ice
- **关联代码**: `backend/ice_engine.py`；`backend/eval_reports/ice_calibration_*.json`

## 背景

`/api/index/ice?symbol=...` 在非上证代码上仍可能套用上证校准表，特征却按该指数计算，概率语义错位。

## 决策

每个指数使用自己历史的校准表；前端跟随指数胶囊切换；启动预热四表；响应标注 `calibrated_on`。

## 后果

- 基线随指数波动率不同，概率只在同指数内比较。
- v3 改为波动率模型后，仍按指数独立估计/缓存，本决策继续有效。

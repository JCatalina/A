> ⚠️ **口径提示 (2026-09-15 更新)**：个股面板展示的“多头评分”是 0–100 技术规则分，未经概率校准；大盘反弹概率面板是**波动率条件化的阈值穿越概率**（同口径下跌 2.5% 的概率与之相等，只判波动幅度不判方向），样本外 Brier skill 约 +0.031~+0.038，冰点分仅作状态描述、实测无增量预测力，详见 [ALGORITHM_DOC.md §15.4](ALGORITHM_DOC.md)。在线“历史相似形态”是样本内价格路径描述，不是可交易回测。美股面板的方向分与建议仓位同为规则型技术评分，未经概率校准，且因行情源无美股分时K线而不含 30/60 分钟级别。方法与局限详见 [ALGORITHM_REVIEW_2026-09-12.md](ALGORITHM_REVIEW_2026-09-12.md)。

## 🌟 核心特性

### 1. ⚡ 个股多维量化看板
- **多维支撑压力价格带聚类**：将均线组、布林通道、形态高低点、未补缺口、斐波那契黄金分割、筹码峰等关键点位进行 $1.5\%$ 容差邻域合并，输出带星级共振的 $S_1 \sim S_3$ 支撑带与 $R_1 \sim R_3$ 压力带。
- **筹码衰减分布模型 (Volume Profile)**：仅在存在可信历史换手率来源时使用换手衰减；否则自动退回成交量分布计算 POC 主筹码峰、获利盘比例与 70%/90% 集中度（估算口径，不解读为真实股东持仓）。
- **自适应维度量化评分**：按市场体制调整维度权重；关闭的维度自动归一化到剩余维度，中性输入保持 50 分。
- **历史相似形态命中率**：样本内价格路径统计，数据不足时如实提示；不是可执行的交易回测或未来胜率。
- **结构化量化交易计划卡**：自动计算建议建仓区间、第一止盈目标位、基于 $2\times ATR$ 与支撑下沿的动态止损位及风险收益比（R:R Ratio）。

### 2. 🌐 大盘多周期宏观研判
- **四大周期切片深度解析**：30分钟（日内微观共振）、60分钟（波段先行指标）、日K线（短线买卖基石）、周K线（中线战略趋势）。
- **多周期价格斜率与方向分**：采用 $Slope = \frac{\Delta Price / 4}{ATR}$ 标准化斜率与方向分 $G \in [-0.95, +0.95]$，精准评估各级别反弹动能与回调风险。
- **正式操作许可与建议总仓位**：输出全天战略许可级别（积极做多、谨慎操作、防守观望）与 0%~90% 动态仓位建议。
- **四大周期 ECharts 毫秒级秒切**：支持完整 OHLC K线、MA 均线组与 MACD 副图。

### 3. 🗽 美股大盘多周期研判
- **四大核心指数**：道琼斯工业 (`usdji`)、标普500 (`usinx`)、纳斯达克综合 (`usixic`)、纳斯达克100 (`usndx`)，行情条可点选切换。
- **日线 / 周线 / 月线三周期结构**：行情源无美股 30/60 分钟K线接口，故不做分时级研判；改为向上取交易所口径**真实月K**（可回溯约10年），形成「月线定战略 · 周线定波段 · 日线定节拍」。
- **完全复用 A 股研判内核**：同一套技术指标、ATR 标准化斜率、方向分 $G$、支撑压力价格带聚类与操作许可矩阵；操作许可的大方向锚点由「周线+日线+60分」上移为「月线+周线+日线」。
- **美股口径差异显式标注**：无涨跌停、盘前盘后可交易、隔夜跳空；周/月K最后一根为未完成周期时标记「周期进行中」，避免把量比偏低误读为缩量。

### 4. 🚀 盘后全市场自动化批量扫描
- **四大规则筛选选股雷达池**：
  1. `SUPPORT_PULLBACK`（短线·回踩强支撑）
  2. `BREAKOUT_PRESSURE`（短线·放量突破）
  3. `MAIN_WAVE_TREND`（中线·主升浪起爆）
  4. `OVERSOLD_DIVERGENCE`（超跌·多重底背离）

### 5. 📰 金融消息面（中国 / 外国）
- **权威媒体聚合**：财联社、华尔街见闻、东方财富、金十、MarketWatch/BBC、CNBC、金融时报等公开源并行抓取（约每 3 分钟，7×24，后台线程不阻塞页面与 A 股任务）；跨源近似重复自动合并（显示「+N 家同报」），保留 48 小时。
- **中国 / 外国按事件主体分类**：不是按媒体国籍——财联社报道的「美光股价」归外国，路透报道的「中国出口」归中国，中美双边事件同时出现在两个分类里。
- **重要度打分（0–100）**：综合事件类别、预期差强弱、涨跌幅、财联社加红、多源同报，分为重大/重要/一般/参考；支持按重要度筛选与排序，低相关资讯自动折叠。
- **消息面速览**：近 12 小时情绪冷暖（按重要度加权）、利好/利空板块热度（点击只看该板块相关消息）、重点事件一键定位。
- **通俗解读（核心）**：一句话结论 + A股/美股/商品三市场方向 + 大白话 + 利好/利空板块及原因 + 传导链 + 接下来盯什么 + 名词小课堂；附识别依据与置信度，涉及指数可一键跳到「大盘多周期研判 / 美股大盘研判」。
- **规则引擎更懂语义**：识别否定（"may not hike" 是偏鸽）、预期反转（"降息预期降温" 是偏鹰）、数值预期差（"公布 3.1%，预期 3.0%"）、涨跌方向（油价涨 vs 跌对应板块完全相反）、库存类反向逻辑（去库超预期利多油价）、美债价格与收益率反向；默认零 Token。
- **可选大模型精读**：设置以下环境变量后，仅对重要度 ≥50 的消息调用大模型（每轮最多 10 条，结果按条缓存不重复计费），规则结论作为初稿与兜底：

| 环境变量 | 说明 |
|---|---|
| `NEWS_AI_API_KEY` / `NEWS_AI_BASE_URL` / `NEWS_AI_MODEL` | 任意 OpenAI 兼容接口（也兼容 `OPENAI_API_KEY` / `OPENAI_BASE_URL`） |
| `DEEPSEEK_API_KEY` | 只填这个即可，自动使用 DeepSeek 官方接口与 `deepseek-chat` |
| `NEWS_AI_MIN_IMPORTANCE` / `NEWS_AI_MAX_PER_REFRESH` | 大模型精读门槛（默认 50）与每轮上限（默认 10） |
| `NEWS_REFRESH_INTERVAL` / `NEWS_RETENTION_HOURS` | 抓取间隔秒数（默认 180）与保留小时数（默认 48） |

### 6. 📋 复盘日报 / 🌅 明日重点（A股自动化报表）
- **复盘日报**：盘前取上一交易日完整收盘数据，红涨绿跌；覆盖市场概览、情绪（涨停/炸板/连板/晋级率）、北向成交额（标注自 2024-08-19 起停止披露日频净买入）、申万一级、估值分位、自建恐贪指数、两融、平均股价等八大维度（含 ECharts）。
- **明日重点晨报**：全球定调（美股/港股/A50/商品）→ A股盘面与政策 → 核心板块与龙头（主线/防御/弹性/观察 + MACD 状态）→ 盯盘要点与风险。
- **存档机制**：涨跌家数与平均股价无历史公开接口，收盘后由调度器自动存档；接口 `GET /api/report/review`、`/api/report/focus`、`/api/report/dates`。

### 7. 🎨 现代化金融看板交互
- **双主题无缝切换**：支持 🌙 **深空星曜（暗色高对比度）** 与 ☀️ **明亮经典（清爽浅色）** 实时一键切换。
- **权威股票中文名与实时快照**：盘中自动与当日最新分时行情无缝拼接，100% 当天最新数据。

## 🚀 快速启动

### 1. 克隆代码仓库
```bash
git clone https://github.com/YOUR_USERNAME/A-Share-Quant-System.git
cd A-Share-Quant-System
```

### 2. 安装 Python 依赖
建议使用虚拟环境：
```bash
# 创建并激活虚拟环境 (可选)
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

### 3. 启动量化分析系统
```bash
cd backend
python -m uvicorn app:app --host 127.0.0.1 --port 8000 --reload
```

### 4. 访问系统
在浏览器中打开：
```
http://127.0.0.1:8000
```

## 📏 预测力的真实量级（请先读）

系统里只有两个输出经过了走前（walk-forward）样本外验证，其余评分都是**状态描述**而非预测（详见 ALGORITHM_DOC.md §14~§16）：

- **大盘 10 日波动阈值概率**（冰点面板）：P(10 日涨 ≥2.5%) 来自波动率预测与零漂移正态假设，与 P(跌 ≥2.5%) 完全相等——高概率只表示波动放大，不是看多信号。四指数 Brier skill ≈ +0.03~+0.04（p ≤ 0.003，科创50 p=0.05），68%/90% 涨跌幅区间为经验分位，历史实际覆盖 67~71% / 87~90%。
- **个股横截面因子分位**（预测卡"横截面因子分位"块）：9 个量价因子的走前 ICIR 加权，样本外逐日 Rank-IC +0.05（NW t 4.0，1487 日）。它只回答"这只股票 10 日相对收益跑赢同类的概率偏高还是偏低"（Q5 51.7% vs Q1 46.4%），**等权多空的均值价差不显著**，不是收益策略。
- 个股"看多评分"、四维雷达、相似形态命中率：点时间评估显示没有横截面预测力（Rank-IC 0.01~0.035，t<2），仅作状态描述。
